Data Flow · v1.0

Sensor-to-Alert Data Flow

Traces one reading cycle end to end — from raw I2C sensor values through feature engineering, ordinal severity classification, LLM interpretation, and conditional alert dispatch.
STAGE 1 · CURRENT PHASE
Demo Mode Data Entry (web UI, ~1 Hz simulated tick)
Scenario player (Normal / Mild AMS / Severe AMS / HAPE / HACE)  ·  manual sliders  ·  Harespod recording replay — all produced via demo_data_source.py, no hardware involved
Emits the same record shape a real sensor would: timestamp,spo2,hr,temp,altitude — via the DataSource interface
FUTURE PHASE 3 — SWAP-IN, NOT BUILT YET
Real Sensor Read (Arduino Uno + MAX30102 / MLX90614 / BMP280, ~1 Hz)
arduino_reader.py (pyserial, 115200 baud) implements the identical DataSource interface as demo_data_source.py — drops in with no change to Stages 2–7 below
STAGE 2
Buffer & Validate
Append reading to rolling buffer (last 10 min) → validate ranges (reject glitches/out-of-range values)
STAGE 3
Feature Engineering
Compute from buffer: spo2_trend_5min · hr_trend_5min · ascent_rate · expected_spo2_at_altitude (delta) · time_at_altitude
STAGE 4
ML Severity Classification (XGBoost ordinal)
Input: raw vitals + engineered features → Output: severity ∈ {Normal, Mild AMS, Severe AMS, HAPE risk, HACE risk} + confidence score
STAGE 5
Hysteresis Gate
Severity must persist above threshold for N consecutive readings (not a single spike) AND cooldown period elapsed since last alert → prevents false-alarm spam from motion artifacts or transient dips
STAGE 6A · ALWAYS ELIGIBLE
LLM Interpretation (Groq / Llama 3.3 70B)
Severity + vitals → plain-language explanation for dashboard chat & alert body. Guardrailed: interprets readings, never diagnoses. Independent of the hysteresis gate (Stage 5) -- but re-generated only when the severity TIER changes, not on every single tick, to stay within free-tier rate limits in a live 1Hz loop.
STAGE 6B · IF GATE PASSES
Telegram Alert Dispatch
Structured message → medical facility chat: severity tier, vitals snapshot, LLM summary, timestamp
STAGE 7
Streamlit Dashboard Update
Live plots refresh · severity badge updates · alert log entry (if dispatched) · chat remains available for live Q&A
