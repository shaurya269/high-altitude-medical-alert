Architecture · v1.0

High-Altitude Medical Alert System

Sensor-to-alert pipeline: Arduino-based vitals capture, ML/DL severity classification, LLM-driven interpretation, and automated escalation for AMS / HAPE / HACE risk.
Current phase: Software-only · Demo Mode (Phase 1–2)
Deploy target: Windows laptop → Hardware (Phase 3) → Cloud (Phase 4)
Status: Week 1 (Data + ML foundation) complete · Week 2 (integration/LLM/alerts/UI) in progress

Design complete in schematik.io. All sensors share the I2C bus (A4=SDA, A5=SCL) at 3.3V, isolated from the Uno's 5V logic via a PCA9306 level shifter. Build begins only after the software system below is working end-to-end in Demo Mode.
01 · Demo Mode Layer — CURRENT PHASE (Windows laptop, software only)
Data Source — demo_data_source.py
Implements a swappable DataSource interface. Three modes, all driven from the web UI: (1) scenario player — Normal / Mild AMS / Severe AMS / HAPE / HACE trajectories, (2) manual slider override for exploring edge cases live, (3) Harespod recording replay. No serial connection, no hardware required. When the future hardware phase begins, arduino_reader.py implements this same interface as a drop-in swap.
02 · Intelligence Layer (Python process)
ML Severity Classifier
XGBoost ordinal model
Input: vitals + engineered trend features
Output: 5-tier severity score
LLM Interpreter
Groq API · Llama 3.3 70B
Turns numeric severity into plain-language explanation + answers live chat questions
FREE TIER
Alert Engine
Hysteresis + cooldown logic
Triggers on sustained severity ≥ threshold, not single-sample spikes
