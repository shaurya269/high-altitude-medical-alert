How the High-Altitude Medical Alert System is built

A sensor-to-alert pipeline: synthetic + real vitals data, an ordinal XGBoost severity classifier, a guardrailed LLM interpretation/chat layer, a hysteresis-gated Telegram bot, and a Streamlit dashboard — all running in Demo Mode against synthetic and replayed data, no physical hardware required.
